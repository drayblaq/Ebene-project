# Images

Drop your product photos here.

Required files (replace the placeholders):
- ebene.png        — Hero/mascot image
- Tag.png          — Price tag image (story section)
- tag.png          — Second tag image (story section)
- placeholder.png  — Default product image (used in cards until real photos are added)

Tips:
- Product images should be square, ~600x600px, transparent background PNG for best results.
- The site uses mix-blend-mode: multiply on light cards, so white backgrounds disappear naturally.
